# On-py — نسخه 1.0.0

ویرایشگر آنلاین پایتون با CodeMirror و Pyodide، با ذخیره‌سازی محلی در مرورگر.

## اجرا
- فایل‌ها را در یک مخزن GitHub قرار دهید و GitHub Pages را برای شاخه موردنظر فعال کنید، یا فایل `index.html` را از طریق یک وب‌سرور محلی باز کنید.
- برای بارگیری CodeMirror و Pyodide اتصال اینترنت لازم است.
- با دکمه «اجرای کد» یا Ctrl/Cmd+Enter برنامه را اجرا کنید.
- Ctrl/Cmd+S برای ذخیره در localStorage مرورگر است.

## محدودیت‌های نسخه 1.0.0
- کد پایتون داخل مرورگر اجرا می‌شود؛ اجرای طولانی یا مصرف زیاد حافظه می‌تواند مرورگر را کند کند.
- `input()` تعاملی در این نسخه پشتیبانی نشده است.
- نصب هر بسته‌ای ممکن نیست؛ بسته‌های pure Python و بسته‌های پشتیبانی‌شده Pyodide مناسب‌ترند.
- فایل‌ها فقط در همان مرورگر و دستگاه ذخیره می‌شوند؛ پاک کردن داده‌های سایت ممکن است آن‌ها را حذف کند. از کد مهم خروجی پشتیبان بگیرید.
- اجرای کد با دسترسی محدود مرورگر انجام می‌شود؛ این محیط برای اجرای مطمئن برنامه‌های سروری یا دسترسی آزاد به سیستم‌عامل طراحی نشده است.
- برای اجرا و بارگذاری کتابخانه‌ها اینترنت لازم است. دستیار هوش مصنوعی عمداً غیرفعال است.
