# On-py — نسخه 1.0.3

ویرایشگر پایتون با اجرای مرورگری Pyodide و گزینه جایگزین اجرای Python نصب‌شده روی کامپیوتر.

## روش معمول
- سایت را باز کن و صبر کن موتور مرورگری آماده شود.
- کد را بنویس و «اجرای کد» را بزن.

## روش جایگزین: Python نصب‌شده روی ویندوز
1. Python 3 را از https://www.python.org/downloads/ نصب کن. در نصب ویندوز گزینه **Add Python to PATH** را فعال کن.
2. از مخزن On-Py فایل `onpy_runner.py` را دانلود کن.
3. فایل را اجرا کن:
   - ویندوز: در پوشه فایل، ترمینال باز کن و بزن `py onpy_runner.py`؛ اگر کار نکرد، `python onpy_runner.py`.
   - macOS/Linux: در ترمینال بزن `python3 onpy_runner.py`.
4. پنجره ترمینال را باز نگه دار.
5. سایت https://brotex-dvplr.github.io/On-Py/ را باز کن.
6. روی «اتصال Python سیستم» بزن. پس از نمایش «Python محلی متصل»، دکمه اجرای کد را بزن.

این اجراکننده فقط روی `127.0.0.1` گوش می‌دهد، مبدأهای مجاز را محدود می‌کند، اندازه کد را به 100KB و زمان اجرا را به 8 ثانیه محدود می‌کند. با این حال کد پایتون روی سیستم خودت اجرا می‌شود و می‌تواند به فایل‌ها/منابع سیستم با دسترسی کاربر دسترسی پیدا کند. فقط کدی را اجرا کن که به آن اعتماد داری. برای قطع اتصال، پنجره ترمینال را ببند.

## محدودیت‌ها
- اجرای مرورگری به اینترنت/CDN نیاز دارد؛ اجراکننده محلی نیاز به Python نصب‌شده و باز ماندن ترمینال دارد.
- `input()` تعاملی در رابط فعلی پشتیبانی نشده است.
- فایل‌های پروژه در localStorage همان مرورگر ذخیره می‌شوند.
- دستیار هوش مصنوعی غیرفعال است.
